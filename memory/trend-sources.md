# Trend Sources

## Channels To Watch
- X / Twitter discussions around embodiment, symbolic systems, and post-productivity work
- Substack essays on spiritual technology, meaning crises, and inner practice
- GitHub and indie-hacker circles where computational self-observation shows up
- Podcast and essay ecosystems around ritual, somatics, and founder self-regulation

## Trend Filter
- Ignore aesthetic-only spirituality trends with no practice depth.
- Ignore generic wellness trends unless they reveal category language worth reclaiming.
- Prioritize signals where people are explicitly asking for rigor, structure, or interpretable inner data.
