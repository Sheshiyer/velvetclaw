# User Segments

## Primary Segments

### Founder In Transition
- High-functioning but internally fragmented
- Wants discernment, not motivation
- Likely entry points: dashboard, mentorship, essays

### Symbolically Literate Practitioner
- Already fluent in ritual, archetype, or embodied work
- Wants more rigor and better interfaces
- Likely entry points: Somatic Canticles, protocols, consultations

### Technical Systems Thinker
- Comfortable with APIs, TUIs, and structured frameworks
- Suspicious of spiritual vagueness
- Likely entry points: Selemene API, TUI, dashboard

### Creative Under Pressure
- Feels pattern collapse, burnout, or meaning drift
- Wants a disciplined reflective practice without flattening complexity
- Likely entry points: essays, narrative layer, starter protocols

## Anti-Segment
- Casual inspiration seekers who want vibes without sustained practice
