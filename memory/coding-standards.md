# Coding Standards

## Product Engineering Priorities
- Preserve clarity between live product behavior and future concepts.
- Instrument meaningful user actions, not vanity events.
- Prefer boring, observable analytics over magical interpretation layers in code.

## Marketing Surface Rules
- CTA, attribution, and event names must be explicit.
- Avoid shipping pages that make claims the product cannot yet support.
- SEO, schema, and tracking work should reinforce category clarity.
