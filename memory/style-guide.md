# Style Guide

## Messaging Hierarchy
1. Self-consciousness
2. Practice
3. Body / breath / rhythm as interface
4. Discernment and pattern recognition
5. Product or offer details

## Structural Rules
- Start with tension or misrecognition.
- Move quickly into a sharper frame.
- End with a concrete invitation, not a motivational flourish.

## Content Do's
- Translate symbolic ideas into operational consequences.
- Use exact terms consistently: self-consciousness, practice, interface, signal, discernment.
- Make the ecosystem legible: software, narrative, protocols, mentorship, physical objects.

## Content Don'ts
- Promise transformation without practice.
- Use startup cliches or consumer-wellness cliches.
- Blur live products and future roadmap items.
